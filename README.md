# Juken
This is a simple study ToDo application for students.
You can easily check your daily tasks and homework deadlines.
It helps you count the days left until your test.
## Required

- Go compiler
- Database (docker / MySQL)

## quickStart

データベースの起動  
dockerを使用する場合
カレントディレクトリで以下をコマンドを実行
```
docker-compose up
```

データベースの停止
```
docker-compose down
```


- goのコンパイル方法

```
go build
go run
```
